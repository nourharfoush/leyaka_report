نظام متابعة اللياقة البدنية — نسخة React

التشغيل:
  cd fitness-react
  npm install
  npm run dev
ثم افتح: http://localhost:5173

البناء للإنتاج:
  npm run build
  npm run preview

الحسابات:
  مدير: admin / admin123
  مدخل: dataentry / 123456
  مشاهدة: viewer / viewer123

المزايا:
- تسجيل دخول + صلاحيات (مدير / مدخل بيانات / مشاهدة)
- لوحة تحكم بعدادات
- 4 سجلات: الزيارات الميدانية / متابعة المعاهد / متابعة الادارات / مؤشرات الاداء
- بحث + اضافة + تعديل + حذف (الحذف للمدير فقط)
- تصدير Excel + استيراد Excel + طباعة
- حساب تلقائي للنسب (المشاركة / المنفذة / المؤشرات)
- حفظ محلي في localStorage (بدون سيرفر) + بيانات مؤشرات جاهزة
- عربي RTL بنفس تصميم Flask
